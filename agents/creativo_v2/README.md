# El Creativo v2 — Pinnacle Holdings Carousel Renderer

Replaces Blotato. Renders 1080x1350 JPG carousels (4:5 vertical IG) from a spec.

## Quick start (POC)

```
cd agents/creativo_v2
npm install
npm run poc
```

Outputs 6 JPGs to `output/poc_t1_slide_{N}.jpg`.

## Tests

```
npm test
```
