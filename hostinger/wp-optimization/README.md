## What this does

Five reversible quick wins, executed via WP-CLI on the Hostinger server:

| # | Script | Effect | Reversible |
|---|---|---|---|
| 0 | `00-backup.sh` | DB dump + page snapshots + astra-settings snapshot | n/a |
| 1 | `01-fix-code-wrappers.sh` | Strips spurious `<code>` wrappers from home, services, about-us (28+ strings) | yes |
| 2 | `02-delete-hello-world.sh` | Trashes `/hello-world/`, `/hello-world-2/` and adds 301 redirects to home | yes |
| 3 | `03-apply-brand-palette.sh` | Repaints Astra global colors to Pinnacle brand (green / gold / white) | yes |
| 4 | `04-install-tracking.sh` | Installs MU-plugin with Meta Pixel + Microsoft Clarity | yes |

**Brand palette applied (T1 Dark Premium):**

- Accent: `#C9A84C` gold
- Text on dark: `#FFFFFF` white
- Footer / alt bg: `#1A1A1A` soft black

## Rollback

Backups land at `~/alex_backups/wp-optimization/<TIMESTAMP>/` and contain:
- `db.sql` — full DB dump
- `home_<pid>.html`, `services_<pid>.html`, `about-us_<pid>.html` — pre-change post_content
- `astra-settings.json` — pre-change theme settings

### Full rollback (DB)
```bash
cd ~/domains/pinnaclegroupwi.com/public_html
wp db import ~/alex_backups/wp-optimization/<TIMESTAMP>/db.sql
```

### Rollback only the brand palette
```bash
cd ~/domains/pinnaclegroupwi.com/public_html
wp option update astra-settings "$(cat ~/alex_backups/wp-optimization/<TIMESTAMP>/astra-settings.json)" --format=json
```

### Rollback only one page
```bash
cd ~/domains/pinnaclegroupwi.com/public_html
wp post update <PAGE_ID> --post_content="$(cat ~/alex_backups/wp-optimization/<TIMESTAMP>/home_<PAGE_ID>.html)"
```

### Remove tracking
```bash
rm ~/domains/pinnaclegroupwi.com/public_html/wp-content/mu-plugins/pinnacle-tracking.php
# Optionally remove the constants from wp-config.php
```

### Restore hello-world redirects from .htaccess
```bash
sed -i '/# PINNACLE_REDIRECTS/,/# \/PINNACLE_REDIRECTS/d' ~/domains/pinnaclegroupwi.com/public_html/.htaccess
```
